# TDG Configuration

## Project Information
- Language: TypeScript (Node.js)
- Framework: Express
- Test Framework: Jest (ts-jest)

## Build Command
npm run build

## Test Command
npm test

## Single Test Command
npx jest <path/to/file.test.ts> -t "<test name>"

## Coverage Command
npm run coverage

## Test File Patterns
- Test files: *.test.ts
- Test directory: src/__tests__/
